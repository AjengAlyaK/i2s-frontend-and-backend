## Features

- View personal data records
- Search by NIK and/or Name
- Add new personal data
- View detail information
- Edit existing data
- Delete data with confirmation


## Tech Stack

**Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript (ES6), Fetch API

**Backkend:** Java 17, Spring Boot, Spring Data JPA (Hibernate), MySQL


## Installation

Database Setup:
```bash
  CREATE DATABASE personal_data
```
Running Backend:
```bash
  cd Backend
  mvn spring-boot:run
```
Running Frontend:
```bash
  Frontend/pages/monitoring.html
```
